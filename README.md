## Quick Start

```bash
# 1. Clone
git clone <repo-url> anveshak && cd anveshak

# 2. Configure
cp .env.example .env   # Fill in your API keys

# 3. Run
docker compose up --build

# 4. Open
# Backend API docs: http://localhost:8000/docs
# Frontend:         http://localhost:5173
```
